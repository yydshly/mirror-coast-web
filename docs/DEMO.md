# 演示与体验范围

在线试玩：https://yydshly.github.io/mirror-coast-web/

## 推荐的一段演示

1. 旧城步行与海堤坐下，展示人物、场景与码头。
2. 到支栈桥清除挡路木箱，走到日志台，展示真实通路变化。
3. 骑车或驾车沿海岸前往南湾，停车后放风筝或观察潮池。
4. 到西岬调试航标，观察海上标灯。
5. 刷新后继续探索，检查本次变化仍被保存。

玩家可以中途停止。时间是节奏参考，不设置通关倒计时。

## 录制自己的演示

按 F9 打开录制，选择纯场景或当前标签页。标签页模式能带上页面文字、地图和操作说明，需要用户在浏览器选择器里确认共享范围。录制结果由用户下载到本机，不上传服务器。
